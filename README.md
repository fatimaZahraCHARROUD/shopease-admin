# 🛒 ShopEase Admin

Full Stack administration platform designed to help businesses manage their entire e-commerce operations from a single dashboard.

## ✨ Features

- Product & category management
- Inventory & stock management
- Customer management
- Supplier management
- Order & delivery management
- Analytics dashboard

## 🛠️ Tech Stack

- React.js - Node.js - Express.js - MySQL - REST API
